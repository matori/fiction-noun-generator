# 創作名詞ジェネレーター

かなで入力した言葉をローマ字に分解し、子音と母音を好きなルールで入れ替えて、カタカナの架空の名詞を作るツールです。

```
さくら → sakura → (a→i, k→s, r→m) → sisumi → シスミ
```

> **バージョン**: v1.4.0（公開先: https://tools.unformedbuilding.com/fiction-noun-generator/）

## 機能

- **かな → ローマ字 → 置換 → カタカナ** の変換。入力中に即時変換し、途中経過も表示します。
- **マッピング**
  - 母音（a i u e o）と子音（基本・拗音・外来音の子音、計 39 種）の行き先をセレクトボックスで自由に設定できます。
  - シャッフル（重複なし／重複あり）を備え、母音は一字ずらし（a→i→u→e→o）もできます。
- **文字列反転**
  - かなの段階で反転するか、ローマ字の段階で反転するかを選べます。
  - ローマ字反転では、先頭に来た母音を末尾へ移すオプションがあります。
  - 末尾の長音符は「削除」か「末尾に保持」を選べます。
- **区切り文字ごとに変換**: `ストレイ・キャット` は「ストレイ」と「キャット」を別々に変換します。
- **設定の保存と共有**
  - 入力と設定は自動で保存され、次に開いたときに復元するか確認します。名前を付けたプリセットとしても保存できます。
  - JSON でエクスポート・インポートでき、URL でも共有できます。
- **コピー形式**: 「変換後のみ」「変換前 → 変換後」「タブ区切り」「コンマ区切り」から選んでコピーできます。
- **生成履歴**: 生成したときの設定も一緒に残り、同じ設定の履歴はまとめて表示します。グループごとに、設定と共有 URL をフッターに付けて「まとめてコピー」できます。設定の詳細の確認と復元ができ、結果はワンクリックでコピーできます。
- **Fluent 2** デザイン。ライト／ダークテーマに対応しています。

## 変換ルール

アプリ内の「使い方」にも同じ内容を載せます。

| 文字 | 入れ替え | 反転 |
|---|---|---|
| 通常の音節（`カ` `キャ` `ティ` など） | 子音・母音とも入れ替える | 1 音節として動く（ローマ字反転では子音と母音に分かれる） |
| `ー` `ッ` `ン` | 入れ替えない | 独立して動く |
| 単独の小書き文字 `ァィゥェォャュョ` | 母音だけ入れ替え、小書きのまま残る | 独立して動く |
| `ヵ` `ヶ` `ヮ` | 通常の `カ` `ケ` `ワ` として扱う | 通常の音節と同じ |

- かな以外の文字（漢字・英数字・空白・記号）は区切り文字です。区切りごとに変換し、区切り文字はそのまま残ります。
- カタカナに戻せない綴りが出たときは、その部分だけ英字のまま出力します（例: `アルカs`）。
- ローマ字の途中経過では、`ー` `ッ` `ン` をかなのまま枠で囲んで表示します（例: `kyaッto`）。区切り文字や小書きの印（`x` `xy`）など、置き換えの対象でない部分は薄く表示します。
- **末尾の長音**: 反転すると末尾の `ー` が先頭に来てしまうため、「削除」か「末尾に保持」を選べます。
- **先頭母音の移動**: ローマ字反転で先頭に来た母音が、元は子音と組んでいた場合に末尾へ移します（`sakura` → `arukas` → `rukasa`）。

### 保存について

- 入力と設定はブラウザに自動で保存されます（ヘッダーの「保存済み」）。次に開いたときに、前回の作業を復元するか確認します。
- 自動保存されるのは最新の状態だけです。残しておきたい設定はプリセットに名前を付けて保存してください。
- 履歴に残っている名詞の設定は、履歴の「設定を復元」で画面に戻せます。戻したあとにプリセットとして保存することもできます。

詳しくは [docs/SPEC.md](docs/SPEC.md) を参照してください。
